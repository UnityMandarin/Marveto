# Marveto collaboration preference

- Treat the user's newest command as the primary source of intent.
- Before editing, break that command into concrete ordered requirements and confirm the intended page/asset mapping from the current repository state.
- Consult older conversation history only when it is necessary to resolve a dependency, preserve an explicit requirement, or avoid undoing completed work.
- Do not re-litigate stale directions when the latest instruction supersedes them.
